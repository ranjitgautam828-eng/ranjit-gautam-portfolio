# Ranjit Gautam Portfolio

A professional portfolio website demonstrating frontend development skills, project organization, and web design fundamentals, built by me Ranjit Gautam, BCIS student at the University of the Fraser Valley.

## 📋 Overview

This project demonstrates my ability to design and build a responsive multi-page website using semantic HTML, modern CSS layout techniques, and modular JavaScript. It highlights my approach to clean UI structure, accessibility fundamentals, and scalable frontend architecture.

## ✨ Features

* Responsive Design – Optimized for desktop, tablet, and mobile viewing
* Minimalist Aesthetic – Focused on clean structure and readability
* Mobile Navigation – Hamburger menu for smaller screens
* Active Link Highlighting – Visual indication of current page
* Contact Form – Interactive form with validation (demo functionality)
* Project Showcase – Grid layout highlighting academic and personal projects
* Certifications Display – Clean presentation of educational achievements
* Dynamic Year Update – Auto-updating copyright year via JavaScript

## 🧠 Key Skills Demonstrated

* Semantic HTML structure and accessibility basics
* Responsive layout using Flexbox and CSS Grid
* Modular JavaScript for UI interactions
* Mobile-first design principles
* Component-based styling approach
* Project organization and maintainable file structure

## ⚙️ Engineering Decisions

* Used vanilla JavaScript instead of frameworks to strengthen core fundamentals
* Implemented system fonts to improve performance and loading speed
* Structured CSS with reusable classes to keep styles scalable
* Designed simple navigation to prioritize usability over visual complexity

## 📚 Challenges & Lessons Learned

* Managing consistent spacing across pages using a grid system
* Balancing visual simplicity with enough content density
* Structuring JavaScript to avoid global scope pollution
* Improving mobile navigation usability

## 🚧 Future Improvements

* Add backend integration for real contact form submissions
* Improve accessibility with ARIA roles and keyboard navigation
* Add project filtering with dynamic data
* Implement performance optimization and Lighthouse improvements
